How the overall outcome is derived

The dataset provides criterion-level labels only. The overall outcome shown here is a transparent aggregation, not ground truth:

  1. R1 any exclusion criterion labelled excluded → likely not eligible
  2. R2 any inclusion criterion labelled not included → likely not eligible
  3. R3 otherwise, any not enough information → undetermined, needs more information
  4. R4 otherwise → preliminarily eligible. not applicable criteria are ignored.

Explanations are generated from the cited evidence sentences only; the model itself emits a label and sentence ids (JSON). Missing evidence is never treated as proof of eligibility or ineligibility. Definitive labels with no cited evidence are flagged as unsupported.

Limitations: tiny training set (37 patients), sentence splitting is rule based, performance on unseen note styles is unknown.
